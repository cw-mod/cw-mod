Установка

Нужен обычный браузер (Chrome, Яндекс, Edge…)

  1. Поставь расширение Tampermonkey — открой сайт по ссылке и нажми кнопку для своего браузера.
  2. Вернись сюда и нажми Установить Варомод. Откроется окно Tampermonkey — там нажми «Установить».
  3. Готово. Зайди в вар и открой настройки: там должны появиться пункты мода.

Скрипт стоит, но ничего не происходит

Иногда браузер блокирует скрипты. Это не баг мода — нужно один раз разрешить их для Tampermonkey.

  • > Chrome / Яндекс / Edge (новые) Нажми правой кнопкой по иконке Tampermonkey → «Управление расширением» → включи переключатель «Разрешить пользовательские скрипты» (может называться Allow User Scripts).
  • > Если такого переключателя нет В адресной строке открой chrome://extensions (в Edge — edge://extensions) и включи «Режим разработчика» справа сверху.

Потом обнови страницу вара. Если совсем непонятно — FAQ Tampermonkey или напиши мне в ЛС.
